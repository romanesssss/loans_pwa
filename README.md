# До свободы — PWA MVP

Минималистичный локальный планировщик долгов.

## Возможности

- кредит, кредитная карта, образовательный кредит, рассрочка и произвольный долг;
- общий долг и обязательная нагрузка;
- календарь платежей;
- сценарий ежемесячного бюджета;
- стратегия «лавина» — дополнительные деньги направляются в долг с максимальной ставкой;
- расчёт даты полного закрытия и процентов;
- локальное хранение в `localStorage`;
- установка как PWA.

## Запуск

```bash
npm install
npm run dev
```

## Production-сборка

```bash
npm run build
npm run preview
```

## Установка на iPhone

Откройте опубликованный сайт в Safari → «Поделиться» → «На экран Домой».

## Ограничения MVP

Расчёт выполняется помесячно. Банковские графики могут использовать ежедневное начисление процентов, комиссии и специальные правила досрочного погашения. Перед финансовыми решениями сравнивайте прогноз с официальным графиком банка.
